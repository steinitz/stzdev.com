# Welcome to TanStack.com!

This site is built with TanStack Router!

- [TanStack Router Docs](https://tanstack.com/router)

It's deployed automagically with Netlify!

- [Netlify](https://netlify.com/)

## Development

From your terminal:

```sh
pnpm install
pnpm dev
```

This starts the site in development mode at http://localhost:3004, rebuilding on file changes. The port is set in `vite.config.ts`; it avoids 3000, which ChessHurdles and the upstream tanstack.com project use.
